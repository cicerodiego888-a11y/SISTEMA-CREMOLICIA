## Objetivo

Tela Mobile de Prestação de Contas com cards recolhíveis e Rateio Inteligente
de Perdas, consumindo apenas APIs oficiais do Motor Comercial.

## Novas telas / rotas

| Rota | Tela |
|------|------|
| `#/comercial/prestacao` | Locator — lista consignações elegíveis |
| `#/comercial/:id/prestacao` | Prestação em cards (resumo, vendas, devoluções, perdas, rateio, financeiro) |
| `#/comercial/:id/prestacao/grade` | Grade de retornos (quantidades) — fluxo anterior |

Menu: drawer **Prestação de Contas** + atalho no hub Comercial.

## Integração com APIs

| Uso | Endpoint |
|-----|----------|
| Abrir prestação | `POST .../prestacao/abrir` |
| Bundle consignação | `GET .../consignacoes/:id` (+ itens) |
| Resumo | `GET .../projections/resumo-prestacao` |
| Rateio (ler) | `GET .../prestacao/rateio-perda` |
| Rateio (gravar) | `PUT .../prestacao/rateio-perda` |
| Finalizar | `POST .../prestacao/fechar` |
| Grade (deltas) | venda / devolução / perda / cortesia (já existentes) |

Mobile **não** recalcula crédito nem inventa totais oficiais; exibe o que a API devolve.
Complemento Cliente/Empresa no compartilhamento é só UX; backend valida a soma.

## Offline

`offline-queue.js` (localStorage):
- Sem rede → enfileira PUT rateio + POST fechar
- Badge **Pendente de Sincronização**
- Em `online` → `flushComercialOfflineQueue()` automático
